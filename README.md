# Duplicate Number Remover

A beginner-friendly Python program that removes duplicate numbers from a list while keeping their original order.

## Features
- Accepts multiple numbers
- Removes duplicate values
- Preserves the original order
- Counts duplicates removed
- Handles invalid input

## Example
Input:
`10 20 10 30 20 40`

Output:
`[10, 20, 30, 40]`

## How to Run
```bash
python duplicate_number_remover.py
```

## Concepts Used
- Lists
- Loops
- Functions
- Conditions
- User input
- try-except
